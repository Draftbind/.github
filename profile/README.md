# Draftbind

**A workspace for authors. From first draft to bound book.**

Draftbind brings drafting, beta reader feedback, formatting and
publishing into one place — so the craft stays the hard part and
everything else gets easier.

Built for independent and self-publishing authors of fiction and
non-fiction.
